## MCP never opens a sign-in page

Check that you configured the **app** URL, including `/mcp`, rather than a
marketing or docs URL:

<Code code={`${appUrl}mcp`} lang="text" />

The default server requires OAuth with CIMD support. An older client may need an
operator-configured legacy mode and pre-registered native client. Repeatedly
copying API tokens will not fix an unsupported authorization flow.

## OAuth returns to the wrong page

Reconnect the MCP client after an app hostname change. For CLI uploads, run login
again with the current app origin. Operators should check that the app and Convex
share `SITE_URL`, and that the GitHub OAuth callback is
`<app-origin>/api/auth/callback/github`.

## CLI says the cloud credential was rejected

<Code code={`plansplease login --cloud-url ${appUrl.replace(/\/$/, '')}`} lang="sh" />

The saved credential is account-, profile-, and origin-specific. It permits
uploads only. Browser sign-in does not repair or revoke a separate CLI credential.
Logout contacts the app to revoke the saved credential before deleting it, so it
needs a connection. Hosted services are currently offline; use the
[local workspace](../development/#full-local-workspace) or check
[hosted availability](../planned-features/).

## An upload is rejected

Check the UTF-8 byte size, not just character count: cloud HTML is limited to
8 MiB. Cloud uploads accept standalone HTML and artifact folders. A quota-enabled
backend can reject an account that lacks available capacity, including pending
cleanup bytes. Hosted service availability is in the
[features reference](../planned-features/).

A temporary provider failure may leave charged capacity until reconciliation.
Do not retry repeatedly with a large document without checking the workspace
and the error result.

## A local URL fails

Use the exact printed port and selected profile. Run `plansplease status` to inspect
the daemon. The link is loopback-only and belongs to the computer where it was
published. If the source changed, publish a new snapshot.

For a folder, use its browser URL to follow the entry redirect. Current `plansplease
get` does not follow that folder-root redirect. Asset paths must be relative to
the folder entry, and the folder must contain root `index.html`.

## A cloud preview is blank

Sign in to the owning account. Verify that uploaded HTML is complete and that its
external assets are still reachable. Generated HTML runs in a sandbox; code that
requires workspace cookies, same-origin storage, or unrestricted navigation
will fail there. Do not remove the sandbox to make an artifact work.
