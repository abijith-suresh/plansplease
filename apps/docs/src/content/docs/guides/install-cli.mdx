The command is `plansplease`. It previews pages on your computer and can upload
them to a compatible account workspace. You need Node.js **24.19.0** and npm
**11.16.0**.

## Install

The previous `planview` command is no longer installed. Update existing scripts
to use `plansplease`. Existing profiles, documents and saved sign-in credentials
keep their locations. The package and repository still use the name `planview`.

The CLI is not published to npm yet. Build an installable tarball from the repository:

```sh
git clone https://github.com/abijith-suresh/planview.git
cd planview
npm ci
npm pack --workspace @abijith-suresh/planview --pack-destination .
```

Replace `FILE.tgz` below with the filename printed by `npm pack`:

```sh
npm install --global --ignore-scripts ./FILE.tgz
plansplease --version
```

## Preview a page

Save a file as `page.html`, then run:

```sh
plansplease publish --open ./page.html
```

The command opens a localhost preview. To preview HTML with CSS, JavaScript or
images, publish a folder containing `index.html` instead:

```sh
plansplease publish --open ./my-page/
```

Local links work on this computer. Publish again after editing to create a new snapshot.

## Upload to your account

Hosted services are paused; see [hosted availability](../../reference/planned-features/).
For a working upload walkthrough, start the [full local workspace](../../reference/development/#full-local-workspace).

<Code code="plansplease login --cloud-url http://127.0.0.1:3000\nplansplease upload --open ./page.html" lang="sh" />

Sign in with the local test account and authorize the CLI when your browser
opens. Upload a standalone HTML file or a folder with root `index.html`; each
upload is limited to **8 MiB**. CLI folders may include supported assets. MCP
bundle uploads accept UTF-8 text assets. UploadThing object URLs are public in
the alpha implementation, so use non-sensitive test content.

See the [CLI reference](../cli/) for profiles, retrieval and other commands,
or [troubleshooting](../../reference/troubleshooting/) if setup fails.
